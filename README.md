## App icon

The launcher icon uses `assets/images/Logo apps in introduction.png` on the
`AppColors.lightCream` background (`#ECEBD8`). To regenerate the Android, iOS,
web, Windows, and macOS icons after changing the logo:

```sh
flutter pub get
dart run tool/generate_app_icons.dart
```

The generator preserves the logo's proportions and adds padding for launcher
masks. Rebuild and install the app to see icon changes; hot reload does not
update native launcher resources.
